# Simple Calculator – CODSOFT Task 2

## About the Project
A simple command-line calculator developed using Python for Task 2 of the CODSOFT Python Programming Internship.

## Features
- Addition (+)
- Subtraction (-)
- Multiplication (*)
- Division (/)
- Division-by-zero error handling
- User input for numbers and operations

## Technologies Used
- Python 3.10+
- Python `match-case` statement

## How to Run
1. Install Python 3.10 or above.
2. Download `calculator.py`.
3. Open a terminal in the file's folder.
4. Run:

```bash
python calculator.py
```

## Sample Output

```text
Enter first number: 10
Enter second number: 5

Choose an operation: +, -, *, /
Enter your choice: +
Result: 15.0
```
